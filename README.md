# المقدمة الآجرّومية — Study Notes

Textbook-style study notes on *al-Muqaddimah al-Ājurrūmiyyah* (Lessons 1–5c), covering pages 1–40 of the class handout.

- Split layout: each scanned handout page (`pages/`) sits on the left and stays in view while you scroll; its English explanation is on the right.
- Fold any handout page into a slim tab by clicking its header. The **Hide handouts / Show handouts** button in the top bar folds or opens all of them at once and keeps your place. On phones the pages stack above the notes and start folded.
- Tap a page to zoom.
- Arabic is set in the KFGQPC Uthman Taha Naskh font (`fonts/`), the Uthmani face used in the Madinah books. Arabic terms stay in Arabic script, and parsing (الإعراب) is given in Arabic.
- Colour key: red = matn and definitions, blue = examples, green = تنبيه / فائدة, purple = الإعراب.

Open `index.html` in a browser, or enable GitHub Pages on the `main` branch.
